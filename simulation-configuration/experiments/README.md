# Ενδεικτικά πειράματα

Τρεις πλήρεις φάκελοι μεμονωμένων πειραμάτων από τις εκτελέσεις του n8n. Τα αρχεία διατηρούνται όπως δημιουργήθηκαν, χωρίς αλλαγές στα δεδομένα.

| Φάκελος | Παράδειγμα | Offered load |
|---|---|---|
| [execution_50/experiment_1](execution_50/experiment_1) | Bandwidth 20 MHz | 200 Mbps |
| [execution_64/experiment_1](execution_64/experiment_1) | Απόσταση UE–gNB 25 m | 200 Mbps |
| [execution_98/experiment_1](execution_98/experiment_1) | RLC buffer 64 KiB | 250 Mbps |

Κάθε φάκελος περιέχει όλα τα αρχεία του συγκεκριμένου πειράματος:

- `config.json`: οι ρυθμίσεις που διάβασε ο C++.
- `results.json`: τα αποτελέσματα που έγραψε η προσομοίωση.
- Ένα CSV: η εγγραφή που προετοίμασε το n8n για ανάλυση.

Τα παραδείγματα έχουν seed 42 και run 1.

Οι διαδρομές μέσα στα CSV είναι οι αρχικές διαδρομές εκτέλεσης στο Ubuntu. Η θέση του UE καθορίζεται από το `ue[0].placement`, όχι από το παλαιό πεδίο `ue[0].position` που παραμένει στο JSON.
